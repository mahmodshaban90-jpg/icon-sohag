# أكاديمية أيكون للألعاب الرياضية - فرع سوهاج

موقع الأكاديمية (HTML ثابت على GitHub Pages).

## تعديل الأسعار والمواعيد وإنستاباي
افتح `index.html` وابحث عن `CONFIG` و `SPORTS` في آخر الملف:
- `instapay`: يوزر أو رقم إنستاباي
- `price`: سعر الاشتراك الشهري لكل لعبة (رقم، أو `null` = اسأل على واتساب)
- `ages` / `days` / `time`: الأعمار والأيام والمعاد
- `address` / `mapLink`: العنوان ولينك جوجل مابس
